# Rehearsio

**Ваше собеседование. Отрепетировано.**

Rehearsio — тренажёр голосовых собеседований. Вставляете текст вакансии (и по желанию резюме) — AI-интервьюер звонит вам, задаёт вопросы вслух именно по этой вакансии, уточняет, если ответ звучит расплывчато, и сам завершает звонок. После — письменный разбор: сильные и слабые стороны, оценка по каждому вопросу, что подтянуть перед настоящим интервью.

**Живая версия: [rehearsioai.vercel.app](https://rehearsioai.vercel.app)**

## Что делает

- Вставляете вакансию → интервью строится по *ней*, а не по общему банку вопросов.
- Живой разговор, а не анкета: приветствие → основные вопросы → закрытие, с реальными уточняющими вопросами на расплывчатые и уклончивые ответы.
- Полностью двуязычно — русский или английский, интервью ведётся на том же языке, что и вакансия.
- Автоматически определяет грейд (стажёр → лид) по тексту вакансии и подстраивает глубину вопросов.
- Бесплатный тариф: одно интервью без регистрации, одно в день с бесплатным аккаунтом. Платная подписка снимает лимит и заменяет браузерный синтез речи на реалистичный AI-голос.

## Почему это не просто обёртка над чат-моделью

Несколько нетривиальных задач, которые пришлось решить по ходу:

- **Собеседование не доверяет модели самой следить за собой.** Этап разговора (приветствие / основные вопросы / закрытие), счётчик вопросов и момент завершения звонка отслеживаются в коде, а не выводятся из ответов модели — LLM ненадёжно считает собственные реплики и не всегда останавливается по команде. Закрывающая фраза произносится из заранее заданного набора, а не генерируется — иначе модель, которая не хочет замолкать, обрывала бы звонок на середине вопроса.
- **Фикс утечки токенов.** Модель часто продолжала генерировать далеко за пределы одного разрешённого вопроса — клиент обрезает речь на первом предложении, заканчивающемся на «?», но сервер при этом продолжал платить за генерацию (и генерировать) всё, что шло дальше. Прокинули `cancel()` от клиента до самого запроса к Groq — заметно сократили впустую сгенерированный текст.
- **Реалистичный голос — одна генерация, а не по одной на предложение.** Изначально текст дробился на предложения на клиенте, чтобы озвучка начиналась как можно раньше — но это означало несколько независимых запросов к OpenAI TTS на один ответ, а TTS-модель не гарантирует одинаковое звучание между отдельными вызовами: голос интервьюера мог слышимо «поплыть» посреди фразы. Починили, объединив весь ответ в один TTS-запрос, с голосом, закреплённым один раз на весь звонок и проверяемым на сервере против зафиксированной персоны (русский интервьюер всегда мужчина, английский всегда женщина — это согласовано с самим голосом, а не только с именем).
- **Аудио стримится, а не сначала скачивается целиком.** TTS-роут отдаёт поток от OpenAI напрямую, но клиент раньше ждал `res.blob()` — то есть весь mp3-файл целиком — прежде чем начать проигрывание, отсюда многосекундная тишина уже после того, как текст появился на экране. Переписали на потоковое воспроизведение через `MediaSource`, с откатом на полную буферизацию для браузеров без поддержки MSE/mp3.
- **Деньги под защитой.** Вебхук Stripe проверяет HMAC-подпись на сыром теле запроса (единственное, что мешает подделать событие «подписка оплачена»), id событий сохраняются, чтобы повторная доставка (Stripe гарантирует «минимум один раз», не «ровно один раз») не применялась дважды, а отменённая, но уже оплаченная подписка продолжает работать до конца оплаченного периода.
- **Защита от абуза по умолчанию.** Лимит запросов по IP на Upstash Redis в проде, с локальным запасным вариантом в памяти процесса, чтобы отсутствие переменной окружения не оставляло API полностью открытым; расход бесплатного лимита отслеживается на сервере (использование интервью выдаёт подписанную cookie, которая проверяется перед стартом каждого разговора) — обойти лимит с клиента нельзя.

## Стек

- **Next.js 14** (App Router) + TypeScript
- **Groq** (`openai/gpt-oss-20b`) — интервьюер и разбор после звонка, потоково
- **OpenAI** (`gpt-4o-mini-tts`) — платный реалистичный голос
- Web Speech API браузера — бесплатный голос и распознавание речи
- **Auth.js** (Google OAuth + почта/пароль) для аккаунтов
- **Neon Postgres** + **Drizzle ORM** для подписок и учёта использования
- **Stripe** для оплаты
- **Upstash Redis** для рейт-лимита в проде
- Деплой на **Vercel**

## Запуск локально

```bash
git clone https://github.com/NellasTerton/rehearsio.git
cd rehearsio
npm install
cp .env.example .env.local   # заполнить как минимум GROQ_API_KEY
npm run dev
```

Всё, кроме `GROQ_API_KEY`, локально не обязательно — без остального приложение работает с бесплатным голосом и без аккаунтов. Что за что отвечает и где взять — в `.env.example`.
